# Frostyx – Fabian

Erster funktionsfähiger Prototyp einer PWA.

Enthalten:
- Frostyx-Bild als dauerhafte visuelle Grundlage
- Kalender für Schule, Fußball, Triathlon und Sonstiges
- Termine hinzufügen/löschen
- automatisches Taschengeld jeden Montag
- 10 € jeden Montag seit Schulbeginn 2026/27 (erster Montag: 21.09.2026)
- Ausgaben mit Betrag und Zweck
- Guthabenberechnung
- Taschengeld-Überblick
- Kristall-Klick-Spiel
- Memory
- kleines Quiz
- Kristalle und Erfolge
- lokaler Speicher im Browser
- PWA-Grundstruktur

Start:
index.html im Browser öffnen.

Für eine echte Installation als PWA sollte die App über HTTPS ausgeliefert werden (z. B. GitHub Pages, Netlify oder eigener Webspace).

Login: Benutzername Fabian, Passwort Fabian2016. Hinweis: Für eine echte öffentliche App sollte die Authentifizierung serverseitig umgesetzt werden; dieser Prototyp nutzt eine lokale Anmeldung im Browser.

PWA: Installierbar auf kompatiblen Smartphones; App-Symbol, Standalone-Modus und Offline-Grundcache sind eingerichtet.
